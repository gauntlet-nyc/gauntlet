# Independent blind-discovery / Recall benchmark

## Gate

An evaluator creates hidden defects in owned synthetic projects and stores ground truth **outside all planner/attacker/fixer mounts and accessible Git refs**. Operator supplies PR title/description, actual code and ordinary requirements, but never bug label/exploit. Persist generated hypotheses and oracle references before execution. Run matching deterministic scripted baseline; independent evaluator scores real effects and reports true found/missed, false positives, reproducibility, attribution, cost. Perturb viewport, CSS naming, tool name and actor/owner relationships to prevent overfitting. Never score a screenshot-only suspicion as confirmed.

## Recall

Seed recorded decisions with explicit direct KB exposure, second-order memory influence, clean exposed outcomes and missing input state. Benchmark exposure provenance precision/recall, control replay match, material flips, cleared, inconclusive, and changed-valid-workflow collateral after patch. Event-audit labels must require authoritative transaction outcomes and known event-time permissions. Separate `event_audit` from `decision_counterfactual` metrics.

## Minimum negative tests

- Hidden truth read attempt blocked even via recursive search or prior Git commit.
- Model proposes unsupported `oracle_id`, worker, arbitrary shell or URL → rejects before execution.
- Head/base fixtures differ → environment error, not confirmed regression.
- Historical control disagrees with original → inconclusive.
- Insufficient destination/payment proof → audit inconclusive, not “wrong person received money”.
- Fix disables legitimate behavior → fails clean regression even if attack blocked.
- Memory retrieved with `as_of` prior to its discovery → hidden; no hindsight leakage.

Report denominator and explicit number of skipped/unreplayable cases in every chart.
