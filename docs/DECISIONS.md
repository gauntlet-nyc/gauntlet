# Architecture decision log

- [ADR 0001: Unified Gate/Recall modular monolith](adr/0001-unified-workflows.md)

Before changing shared APIs, provider model, trust boundary, RunEvent or data retention: add a numbered ADR with `Context / Decision / Alternatives / Consequences / Migration / Rollback / Approvers`. A/B/C sign off before implementation. A coding agent must never resolve incompatible specs via unilateral model edits.
