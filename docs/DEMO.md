**Act B — Gate / AI:** separate PR with AI refund tool; planner elects agent/tool worker based on changed permission boundary; malicious synthetic retrieved text attempts privileged tool invocation; show actual gateway and test-ledger result plus Arize trace; backend policy fix blocks unauthorized effect and legitimate refund still works.

**Act C — Recall:** detect code issue predating PR; traverse recorded synthetic event lineage; event audit finds actual forbidden transactions (not just suspicious caller IDs); show historical case queue, review-only action. For a true AI memory poison, show direct + second-order lineage then recorded, control and counterfactual decision; classify tainted/cleared/inconclusive with Arize experiment and data completeness.

**Elevator pitch:** “CI passed because no one wrote the test. Gauntlet read what changed, invented the test, proved a failure in isolation and verified a repair. When the bug already shipped, Recall identifies historical exposure and separates documented harm from assumptions.”
